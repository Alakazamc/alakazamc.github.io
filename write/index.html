连上 GitHub

这个页面跑在线上，没有你电脑上的小服务可用，所以发布走 GitHub 官方接口。 需要一张只对这一个仓库有效的通行证。

  1. 点开 创建细粒度 token
  2. Repository access 选 Only select repositories → 勾 alakazamc.github.io
  3. Permissions → 找到 Contents → 选 Read and write（其他全都留 No access）
  4. 设个过期时间（建议 90 天），点生成，把 github_pat_ 开头那串粘到下面

这张通行证只存在你这台设备的浏览器里，不会发到任何第三方服务器 —— 它只用来调 api.github.com。想撤销随时去 GitHub 设置里删掉即可。
