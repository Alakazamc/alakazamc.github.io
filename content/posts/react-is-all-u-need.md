MIT 最近有一个实验很火：GPT-6 Astra 直接改 Qwen3.5-0.8B 的权重，只动了 0.016% 的参数，MATH-500 从 7.9 分拉到 48.1 分。不用显卡去训练，也没有梯度下降，就是一个大模型在 Python 环境里读权重、改权重、跑一遍看看、接着改。

![Astra 修改 Qwen 权重的实验报道](../assets/uploads/react-is-all-u-need/astra-report.jpg)

看完以后，我在眩晕瘫坐之余思考，难道 astra 把矩阵数字也训练进去了吗？绝对不可能。这个实验里真正起作用的，是一个 2022 年就有的东西——ReAct，一个让模型边想边做、能看到结果的环。

顺着这个环往下看，很多事的顺序就清楚了：agent 框架为什么突然不重要了，小模型的能力为什么能被直接改出来，还有，为什么连 DeepSeek 都开始认真做产品。

## 框架已经没有核心了

我的判断比较直接：agent 框架已经是上上个时代的东西。

dsh 最近一直很火爆，思路是“一切皆插件”。模型是插件，工具是插件，会话、沙箱、UI 是插件，连 agent loop 本身也是插件。真正剩下的内核只管装插件、卸插件、处理依赖，对“agent 应该怎么工作”不发表意见。

框架没有核心了，只剩组合。

LangChain 1.0 也是同一个信号。2025 年 10 月，它把入口收成一个 create_agent，废弃了 create_react_agent，老 chains 挪进 langchain-classic，主要卖点变成 middleware 和可恢复执行。以前框架帮你写循环，现在循环本身不值得卖了，大家开始卖循环外面的状态、审批、追踪。

说到这，给想找 agent 实习的人一句实话：**LangChain、LangGraph 这些都过时了，对求职毫无用处。**

花两周啃 LangGraph 的 StateGraph，不如花两天手写一个循环，再花一周把状态、权限、成本、失败恢复做对。框架的 API 半年一换，LangChain 1.0 自己就把入口推翻重来了一次。面试官真正会问的是上下文怎么拼、工具怎么设计、死循环怎么拦、跑飞了怎么查。这些框架不教，它只负责藏起来。

简历上写“熟悉 LangChain”，换不来面试官多看你一眼。这句话只说明，你把时间花在了一层正在消失的抽象上。

## transformer 带来了大模型时代，而 ReAct 是被低估的那一半

再说为什么我觉得 ReAct 重要。

Transformer 解决的是把能力存进权重，ReAct 解决的是让模型在环境里把能力用出来。这两件事是配套的。只有前者，模型懂得再多，也只是一个一次性给答案的系统。

Astra 这个实验最说明问题的地方，在于它怎么做到的。“数学提高 6 倍”这个数字倒在其次。研究者给了它不同的前向计算预算：10 次、25 次、50 次，成绩分别是 12.3%、14.1%、48.1%。

![反馈轮次与成绩](../assets/uploads/react-is-all-u-need/fig-budget.jpg)

模型没变，知识没变，只是多跑了几十轮“改完看看”。

Qwen 自己也一样。它会数学，只是总陷进重复推理，回答写满 32768 个 token 还交不出答案。Astra 把这个问题从第 15 层和第 19 层的权重里拆掉以后，GSM8K、IFEval 也跟着涨了。原来模型里已经有了东西，但是之前发挥不出来。

![修复前后四项指标](../assets/uploads/react-is-all-u-need/fig-metrics.jpg)

没有 ReAct，模型有知识、有推理，但看不到环境，也拿不到反馈。Astra 能修 Qwen，是因为它能观察 Qwen 哪里坏了，改一刀，再观察结果。这是闭环的力量。

还有一件事挺关键：读懂权重这种能力，不太可能来自现成训练语料。没人会把几亿个浮点数配一句“这个网络会玩打砖块”写在网上。更像是模型把从代码、数学、科学文本里学到的东西迁移过来了。环给了它一个机会，把这种原本说不出来的能力变成具体操作。

当然，环不能凭空造能力。研究者换了一个本来不怎么死循环的 Gemma 3 270M，同样的方法只从 6.8% 推到 7.7%。它解开的都是模型原本就有的能力。

## 产品侧重要，是因为模型外面那圈重要

以前模型公司可以只比参数和榜单，因为大家默认模型强就够了。现在越来越明显：同一个模型，放在不同 harness、不同工具、不同反馈环境里，表现可以是两个东西。

产品侧的重量，落在模型外面那一圈。

DeepSeek 的组织调整是个很直白的信号。2026 年 10 月，它把 Harness、Web、App、Platform 合成产品部，负责人是原来 Harness 的崔添翼。做运行环境的人开始管产品，这比“高傲的模型公司低头做产品”更能说明问题。

![DeepSeek 产品部报道](../assets/uploads/react-is-all-u-need/deepseek-product.jpg)

梁文锋说 coding agent 是重点：读代码、定位问题、调工具、执行、检查结果，正好覆盖一个 agent 需要的完整循环；而且优质的 agent 内部数据能形成数据飞轮，ReAct 的轨迹还在反哺预训练。这个判断和 Astra 的实验其实是同一件事：能力不是只在训练里增长，也在使用环境里被激发、被修正、被固定下来。

DeepSeek 做产品，商业化的成分当然有。更实际的原因是，模型能力要继续变成实际能力，就必须有自己的环境和反馈闭环。

## 最后

所以说：React is all u need。

模型重要，工程也重要。今天真正稀缺的，是一个能让模型动手、看结果、继续改的环境，而不用再套一层框架。

剩下的，都是产品和工程。
