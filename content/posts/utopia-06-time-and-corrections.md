> 知识更新要回答两件事：事情何时成立，以及系统何时知道。更正不能把“后来才知道”伪装成“一开始就知道”，依赖旧前提的结论也要重新核算。

# 交接与更正走不同的路

1. 正常交接：3月1日任命张三，4月1日李四接任。若“负责人”被声明为状态关系且每个项目同一时刻只有一人，时间线可让张三的区间在4月1日结束。
2. 迟到更正：4月10日核验发现实际交接是4月5日，并在当天完成更正。这是修改此前认知；改类型化事实区间时，旧行作废并留下修正行，不能把4月10日当成世界轴起点。
3. 交叉查询：问“4月3日谁负责”，按4月9日的认知可答李四；按更正后的认知可答张三。前者选旧 as_of，后者用当前 as_of，at都指4月3日。
4. 证据不等于事实数：两份材料支持同一断言时可汇入同一类型化事实。撤掉一份材料，要检查是否还有支持，不能直接认定事实全失效。

> ❗
> 时间解析与依赖重算有具体入口：resolve_time更新开放陈述日期，不会自动排类型化物化。短语对齐或人工绑定交付任务调用materialize；另一个materialize_inferences任务调用reasoning::materialize，对比当前前提与派生集合，让不再成立的旧结论失效。

- 类型化状态的区间更正保留旧版本；开放陈述的时间解析却可原地UPDATE，部分见证同步也是更新。不要据此承诺所有内部变更都有完整历史。

- 没有可靠日期就保留未知；不能用上传时刻冒充现实起点。时间解析若起点无法锚定，会标为C级，此时不能自动关闭前任；高置信度数字也不能替代时间依据。“没写结束”与“已结束但日期未知”也应分开。

# 用一张核对卡检查更新

| 检查点 | 应留下的解释 |
| --- | --- |
| 原句怎么说 | “从4月5日起接任”是事实起点；“4月10日核验”是核验材料的日期。先分清句子谈的是哪一种时间。 |
| 关系是什么性质 | 负责人按state状态处理；只有声明了函数型或逆函数型的状态关系，才进入对应唯一性时间线，不能把所有新信息都当作自动覆盖旧信息。 |
| 更正在哪一层 | 直接修正类型化区间与重新解析开放陈述不是同一入口。前者走旧行作废加修正行；后者还要检查类型化视图有没有真正重算。 |
| 结果何时更新 | 类型化物化、时间线对账、规则推理各有入口。任务排队、执行成功、答案更新是三个状态，不能只看到“已排队”就宣称全链完成。 |

- 先固定一个轴：只想比较认知变化，就让at一直是4月3日，仅改变as_of；只想观察现实交接，就保持当前认知，仅把at从4月3日移到4月6日。两个轴一起拖，难以判断答案为什么变化。

- 保留日期的精度：材料只写“4月”，就不能伪装成准确到秒。状态的区间按半开区间理解：交接边界之后由继任者接手，而不是两人都因边界日期重复在岗。

- 检查不相干的结论：如果高风险只依赖A项目风险85和阈值80，改负责人不应让它失效。若把风险更正为70，重算后高风险才应退出当前有效结果。

> 练习记录可以只写四列：原句、世界时间、何时入库或更正、受影响的答案。先手工填对，再在部署里验证；本课的日期结果是教学预期。

# 自测与源码

1. 4月10日发现4月5日交接，两个日期相同吗？答案：前者是获得更正的记录时刻，后者是世界时间；报告日期还要独立看。
2. 改了风险读数，高风险结论立即正确吗？答案：不能假定。先更新对应类型化前提，再走推理重算；规则只影响依赖它的结论。
3. 删掉一条证据就删掉事实吗？答案：先检查其余支持，可能仍有另一份材料支持同一事实。
