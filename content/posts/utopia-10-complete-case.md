# 把答案和更正串起来

1. 保留材料：先让解析、分块和检索可用，再抽出开放陈述，保留每条原句及其证据。类别词与关系短语对齐后才计算类型化事实，别把相似词直接当相同关系。
2. 先声明意义：负责人是项目到人的状态关系，同一时刻每个项目只有一位；主管是人到人。问“负责人的主管是谁”时，沿这两个明确的关系查路径，不能改用模糊的“相关”边。
3. 区分结论：D1和D2有效区间重叠时，两跳路径可答“张三的主管王五”。再由人写“项目风险≥80→高风险”规则，风险85触发高风险；风险缺失时不替它填0。
4. 处理交接：D3先把张三的负责人区间闭合于4月1日。D4是迟到更正，经核验后由Editor修正相关类型化区间为4月5日，保留旧行，再按前提重算派生。不能只上传D4就假定全链自动完成。
5. 只动相关依赖：王五路径答案依赖负责人和主管关系，相关查询需按更正后的前提重查；高风险依赖风险85和阈值规则，不会因为换负责人自动消失。李四主管未知时，不编造新升级联系人。

| 问题 | 教学预期 |
| --- | --- |
| at=4月3日，as_of=4月9日 | 按更正前认知：李四负责 |
| at=4月3日，采用当前认知 | 按D4更正后：张三负责 |
| at=4月6日，采用当前认知 | 李四负责；其主管未提供 |

日期只给到日；as_of实际筛选记录时间戳，测试时应选材料入库前后的明确时刻。教学表设定D2在所问时段有效，各材料同日入库且绑定、更正与必要重算已完成，不能直接当部署结果。

# 用反例检验你是否真的理解

| 改动 | 应如何解释 |
| --- | --- |
| D2只说张三认识王五 | 两个人可连接，不代表主管关系成立。路径有连接和路径满足问题是两回事。 |
| D2只在5月才成立 | 不能拿5月的主管关系解释3月的升级对象；查询相关关系时要核对共同有效时段。 |
| 另有D5也支持风险85 | 删D1后先检查D5是否仍支持同一事实；证据条数不是事实条数，也不是业务风险的加法。 |
| 将风险更正为70 | 核验并更新类型化前提后重算；若无其他有效支持，高风险派生失效。失效记录保留，但外部接口不保证完整历史证明快照。 |

1. 第一次实践只做可核验的部分：用四份小材料追踪摄入、开放陈述、绑定和类型化事实。确认每一步都能回到原文，再比较两种时间查询，避免一次导入大量文件后无法解释差异。
2. 第二次才测试派生：加入明确的风险属性和阈值规则，检查证明是否引用正确读数与规则。风险值缺失、变成75、或前提时间不相交时，应该分别说明未知、不满足、无共同成立时段，不能统称“系统坏了”。
3. 第三次记录更新路径：写下你实际触发的是时间解析、类型化物化还是推理任务；等待每个任务完成再查结果。如果只改开放日期，没有补跑物化，就先解释这个实现缺口。

> ❗
> 这里的王五是沿“负责人→主管”读到的两跳路径答案，不是当前系统支持任意两谓词链规则的证明。规则引擎有受限一跳连接能力，但不能因此发明“任意路径自动生成关系”。高风险分类才是本案例明确配置的规则派生。

> 课堂完成的标志不是“回答像对的”，而是换一份材料、换一个时刻或撤销一条支持后，你能提前写出预期，再用同一个入口验证它。

# 结业自测与实践检查

1. 把“主管”换成“认识”，王五结论还成立吗？答案：不成立，关系意义和规则前提变了。
2. 没提供李四主管，能答“没有主管”吗？答案：不能，只能说当前未知。
3. D4更正后要重算哪些结论？答案：重查依赖负责人区间的路径答案；风险派生按其自身前提重算，不因交接直接撤掉。

- 为每条答案定位原句、实体身份、关系方向和证据。

- 分别固定at与as_of，检查更正前后答案及派生证明。

- 用Viewer与Editor验证权限；记录失败步骤，区分配置、模型与代码问题。
